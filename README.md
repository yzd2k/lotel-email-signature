# Lotel Email Signature Assets

Public image assets used in the Lotel email signature.

## CDN base URL

`https://cdn.jsdelivr.net/gh/yzd2k/lotel-email-signature@main/`

Examples:
- [Animated logo](https://cdn.jsdelivr.net/gh/yzd2k/lotel-email-signature@main/lotel-logo-motion.gif)
- [Portrait](https://cdn.jsdelivr.net/gh/yzd2k/lotel-email-signature@main/lotel-portrait-email.png)
- [Mail icon](https://cdn.jsdelivr.net/gh/yzd2k/lotel-email-signature@main/icons/mail.png)

The images in this repository are publicly accessible for rendering in email clients. Keep filenames and the `icons/` paths stable. Verify the finished signature in a real received email before rolling it out.
